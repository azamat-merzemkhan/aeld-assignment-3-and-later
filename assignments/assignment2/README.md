# Assignment 2 validation

Implemented with OpenAI Codex assistance. No other students' solutions were used.
The starting point is the official course assignment2 branch and autotest framework.

## Build and test

From the repository root on Linux:

```sh
git submodule update --init --recursive
./full-test.sh
make -C finder-app clean
make -C finder-app
./finder-app/writer /tmp/writer-example.txt 'AELD_IS_FUN'
make -C finder-app clean
make -C finder-app CROSS_COMPILE=aarch64-none-linux-gnu-
file finder-app/writer
```

The caller must create the destination directory before running writer.
The program overwrites the file, writes the supplied string followed by a newline,
and returns 1 for invalid arguments and file IO errors. It logs the write at
LOG_DEBUG and errors at LOG_ERR, using the LOG_USER facility.

## ARM toolchain evidence

`cross-compile.txt` is actual output of `aarch64-none-linux-gnu-gcc -v` and
`-print-sysroot`, generated by GitHub Actions on Ubuntu 24.04 with the official
Arm GNU Toolchain 13.3.Rel1. `fileresult.txt` is actual output from `file` after
cross compilation. The workflow regenerates and compares both evidence files.

Toolchain source and course instructions:
https://github.com/cu-ecen-aeld/aesd-assignments/wiki/Installing-an-ARM-aarch64-developer-toolchain

GitHub Actions also runs the course unit tests and full assignment tests, plus
checks for overwrite behavior, paths containing spaces, empty strings, missing
or extra arguments, nonexistent parents, directories, and delayed write errors
using `/dev/full`. Syslog facility, severity, and message content are checked by
receiving the real Unix datagrams in the isolated test container.
